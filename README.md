# Billing_app
A full-stack Billing Management System built with PHP, MySQL, and custom CSS. Automates invoice generation using TCPDF and dispatches invoices via email using PHPMailer. Includes server-side pagination and input validation for improved reliability, along with resolved SQL and SMTP integration issues encountered during development.
Automated PDF invoice generation (TCPDF)
Automated email dispatch (PHPMailer)
Server-side pagination for large datasets
Input validation and error handling
Custom-styled UI (no framework — hand-built CSS)
